[[sec:binary-types]]
=== Binary Types (LOB Types)

PartiQL supports binary large object (LOB) types for storing raw binary data.

[cols="1,1,3", options="header"]
|===
|Type |Bit Size |Description

|`BLOB`
|Variable (unlimited)
|Binary Large Object - raw binary data

|`CLOB`
|Variable (unlimited)
|Character Large Object - large text data

|`BINARY(n)` / `VARBINARY(n)`
|Variable (≤ n bytes)
|Binary data with maximum length n bytes
|===

*EBNF Syntax for Binary Literals:*
[source, ebnf]
----
blob_literal = "{{", { { hex_digit, hex_digit } }, "}}" ;

clob_literal = "{{", '"', { clob_character | escaped_character }, '"', "}}" ;

clob_character = ? any Unicode character except quotes and backslash ? ;
----

*Examples:*
[source, partiql]
----
{{ 48656C6C6F }}              -- BLOB: "Hello" in hex
{{ "This is a CLOB" }}         -- CLOB
{{ DEADBEEF }}                 -- BLOB: 4 bytes
----
