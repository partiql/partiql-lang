[[sec:binary-types]]
=== Binary Types

PartiQL supports binary large object (BLOB) types for storing raw binary data.

[cols="1,1,3", options="header"]
|===
|Type |Bit Size |Description

|`BLOB(p)` / `BLOB`
|Variable (unlimited)
|Binary Large Object - raw binary data
|===

*EBNF Syntax for Binary Literals:*
[source, ebnf]
----
bit_string_literal =
    "B" quote { bit } quote [ { separator quote { bit } quote } ];

hex_string_literal =
    "X" quote { hexit } quote { separator quote { hexit } quote };

binary_string_literal =
    "X" quote { hexit hexit } quote { separator quote { hexit hexit } quote };

bit = "0" | "1";

hexit = digit | A | B | C | D | E | F | a | b | c | d | e | f;
----
