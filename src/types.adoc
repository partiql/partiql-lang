== Data Types

PartiQL supports a rich type system that extends SQL's type system to accommodate semi-structured and nested data. The type system is designed to be compatible with both SQL's traditional scalar types and Ion's comprehensive type system, enabling PartiQL to work with both relational and semi-structured data.
