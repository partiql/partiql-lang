[[sec:string-type]]
=== String Type

PartiQL supports text data using Unicode character strings. String types are variable-length and can represent text in any Unicode encoding.

[cols="1,1,3", options="header"]
|===
|Type |Size |Description
|`STRING`
|Variable (up to implementation maximum)
|Variable-length character string up to implementation maximum
|===

*Character Encoding:*

* Strings are Unicode character sequences
* Internal representation is implementation-defined (UTF-8, UTF-16, etc.)
* Each character is a Unicode code point (21 bits effective range: U+0000 to U+10FFFF)

*EBNF Syntax for String Literals:*
[source, ebnf]
----
string_literal = "'", { string_character | escaped_character }, "'" ;

string_character = ? any Unicode character except quotes and backslash ? ;

escaped_character = "\", ( "'" | '"' | "\" | "/" | "n" | "r" | "t" 
                  | "b" | "f" 
                  | "u", hex_digit, hex_digit, hex_digit, hex_digit
                  | "U", hex_digit, { hex_digit } ) ;

hex_digit = digit | "a" | "b" | "c" | "d" | "e" | "f"
          | "A" | "B" | "C" | "D" | "E" | "F" ;
----
