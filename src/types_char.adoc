[[sec:string-type]]
=== String Type

PartiQL supports arbitrary-length text data with the string data type.

[cols="1,1,3", options="header"]
|===
|Type |Size |Description
|`STRING`
|Variable (up to implementation maximum)
|Variable-length character string up to implementation maximum
|===

*EBNF Syntax for String Literals:*
[source, ebnf]
----
character_string_literal =
    quote { character_representation } quote
    [ { separator quote { character_representation } quote } ] ;

character_representation = non_quote_character | quote_symbol ;

quote_symbol = quote quote ;
----
