[[sec:timestamp-types]]
=== Datetime Types

PartiQL supports temporal data types for representing dates, times, and timestamps with varying levels of precision.

[cols="1,1,3", options="header"]
|===
|Type |Size |Description

|`DATE`
|Implementation-defined
|Calendar date (year, month, day)

|`TIME` / `TIME(p)`
|Implementation-defined
|Time of day with optional precision p (fractional seconds)

|`TIMESTAMP` / `TIMESTAMP(p)`
|Implementation-defined
|Date and time with optional precision p and optional timezone

|`TIMESTAMP WITH TIME ZONE`
|Implementation-defined
|Timestamp with explicit timezone information
|===

*Precision:*

* Precision p specifies the number of fractional second digits (0-9)
* Default precision is implementation-defined (typically 6 for microseconds)

*EBNF Syntax for Timestamp Literals:*
[source, ebnf]
----
date_literal = "`", year, "-", month, "-", day, "`" ;

time_literal = "`", hour, ":", minute, ":", second, [ ".", fraction ], 
               [ timezone ], "`" ;

timestamp_literal = "`", year, "-", month, "-", day, 
                    "T", hour, ":", minute, ":", second, 
                    [ ".", fraction ], [ timezone ], "`" ;

year = digit, digit, digit, digit ;
month = "0", digit | "1", ( "0" | "1" | "2" ) ;
day = ( "0" | "1" | "2" ), digit | "3", ( "0" | "1" ) ;
hour = ( "0" | "1" ), digit | "2", ( "0" | "1" | "2" | "3" ) ;
minute = ( "0" | "1" | "2" | "3" | "4" | "5" ), digit ;
second = ( "0" | "1" | "2" | "3" | "4" | "5" ), digit ;
fraction = digit, { digit } ;
timezone = "Z" | ( "+" | "-" ), hour, ":", minute ;
----

*Examples:*
[source, partiql]
----
`2023-12-25`                           -- DATE
`14:30:00`                             -- TIME
`2023-12-25T14:30:00Z`                 -- TIMESTAMP (UTC)
`2023-12-25T14:30:00.123456-08:00`     -- TIMESTAMP with microseconds and timezone
`2016-08-03T08:56:52.415Z`             -- TIMESTAMP from Ion
----
