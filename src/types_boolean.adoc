[[sec:boolean-type]]
=== Boolean Type

The boolean type represents logical truth values.

[cols="1,1,3", options="header"]
|===
|Type |Bit Size |Description

|`BOOLEAN` / `BOOL`
|1 bit (typically 8 bits storage)
|Logical truth value: TRUE or FALSE
|===

*EBNF Syntax for Boolean Literals:*
[source, ebnf]
----
boolean_literal = TRUE | FALSE ;
----

*Note on NULL:* While SQL's three-valued logic includes TRUE, FALSE, and NULL, in PartiQL NULL is treated as an absent value (see <<sec:absent-values>>), not as a boolean value.

*Examples:*
[source, partiql]
----
TRUE
false
1 > 0        -- evaluates to TRUE
'a' = 'b'    -- evaluates to FALSE
----
